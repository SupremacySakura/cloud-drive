知序的扩展
为对话模型与 Embedding 分别选择默认值；Embedding 模型额外记录维度。示例列表仅用于交互预览，不作为实时模型目录。
供应商与协议
预设目录可以包含不同协议。原型展示 OpenAI Chat Completions、Responses 和 Anthropic Messages；正式实现仅启用经过适配验证的协议。Embedding 使用 OpenAI 兼容 /embeddings，不借用聊天协议。
目录不是能力检测
获取 /models 成功不代表可调用，也不证明模型支持 Embedding。用途和维度须手动指定并通过对应测试确认；不提供 /models 的服务仍可手动添加。
凭据安全
预设 API Key 认证和自定义无认证入口；本地无认证端点需要部署侧允许。不得将真实密钥写入原型、本地存储或日志。输入 demo 表示成功场景，demo-fail 表示失败场景。
变更与删除
Provider ID 保存后不可修改。删除默认模型使用的供应商时阻止操作，要求先切换默认模型。Embedding 身份或维度变更提示重建，暂不提供实际重建入口。
正式实现
Go 是模型配置与凭据的业务属主，Mastra 通过受保护内部接口获取；基础设施环境变量与用户模型配置分开。模型配置保存后供后续任务使用，不修改正在运行任务的配置快照。

本轮只设计模型设置与服务状态，不扩展任务中心、账户编辑或用量统计。
