转场与层级规格

抽屉打开：面板从左侧滑入（x: −100% → 0），弹簧 damping 0.8 / response 0.3，可打断、手势速度交接；scrim rgba(0,0,0,0.40) + blur 6px 同步淡入 200ms。

抽屉关闭：点 scrim 或「关闭导航菜单」按钮，离场 150ms 沿同一路径返回（镜像规则）。路由跳转（route.fullPath 变化）后抽屉自动收起。

z 序：基础内容 0 → 移动顶栏（material，sticky）20 → 抽屉层 40/50 → Toast 60。

顶栏与按钮反馈

移动顶栏：60px 高、material 半透明 + hairline 底边，标题为「云盘 + 当前导航名」（currentNavLabel，匹配失败回退「云盘」）。

菜单按钮 40×40 热区，pointer-down 即 scale(0.92)（图示右侧为按下定格）；关闭按钮为 40px icon-btn，hover surface-secondary。
