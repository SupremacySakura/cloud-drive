## 教训与差异

- 配置多个关联表不能只做独立 CRUD；默认引用与供应商生命周期必须在同一事务串行校验。
- 只给字段加 `json:"-"` 不足以保证所有使用场景安全；公共视图应主动清除密文字段，错误不回显请求值。
- GORM 查询结构体主键非零会增加隐式主键条件，SQL mock 须匹配实际查询。
- 保存端点结构合法不代表允许发起网络请求，后续调用必须添加 DNS 与地址防护及本地精确允许名单。
- 原设计单表 model_configs 细化为三表，原型中的 Anthropic 协议暂未适配。Brain 的旧项目名称/测试描述按只读协议未改，差异见本任务和权威文档。
